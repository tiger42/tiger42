Hi, I'm Olli – a developer, mostly working with PHP, JavaScript, TypeScript and Python, and sometimes C/C++ when an ESP32 or another microcontroller is involved.

I build mechanical keyboards, and sometimes the tools around them. Soldering and tinkering are part of the fun – like giving a [1994 IBM Model M](https://keyshelf.app/en/gallery/Olli/94) a new USB controller board. My smart home runs on Home Assistant, and lately I've been hooked on Claude Code, to the point of writing mods for it.

**⌨️ Keyboards**
- [keyshelf.app](https://keyshelf.app) – a free home for mechanical keyboard collections, with a database of 1000+ switches
- [hjs-weikav-keymap-patch](https://github.com/tiger42/hjs-weikav-keymap-patch) – unlocks the ISO key, the Fn key and the Fn layers on HJS and Weikav keyboards

**🤖 Claude Code**
- [claude-mods](https://github.com/tiger42/claude-mods) – live bars for the 5-hour and weekly usage limits, plus a color picker for the session color
